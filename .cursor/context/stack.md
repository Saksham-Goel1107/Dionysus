# Tech Stack Reference

- **Framework**: Next.js 15 (App Router), React 19
- **Language**: TypeScript 5 (strict)
- **Styling**: Tailwind CSS, tailwind-merge, shadcn/ui, Radix UI
- **State/Data**: React Query, tRPC 11, Zod, SuperJSON
- **Database**: PostgreSQL + Prisma (vector extension)
- **Auth**: Clerk
- **Payments**: Stripe
- **AI/LLM**: Google Generative AI, LangChain, AssemblyAI, Groq SDK (optional)
- **Realtime/Media**: LiveKit
- **Email/Infra**: Nodemailer, Vercel Functions, Sentry

See `package.json` for exact versions.
