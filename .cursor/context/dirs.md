# Directory Map

- `src/app/` — routes, layouts, server handlers, middleware-aware pages
- `src/components/` — reusable UI components
- `src/lib/` — utilities, third-party integrations
- `src/server/` — React Query client/server, server utilities
- `src/trpc/` — tRPC routers, context, procedures
- `src/hooks/` — React hooks
- `src/types/` — shared TypeScript types
- `prisma/` — Prisma schema, migrations
- `public/` — static assets
