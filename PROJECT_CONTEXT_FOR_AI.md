# Dionysus Project Context (Short)

- **Purpose:** Enterprise GitHub analytics & collaboration SaaS (Next.js, TypeScript, tRPC, Prisma, PostgreSQL)
- **Features:** AI code analysis, meeting transcription, team collab, repo insights
- **Frontend:** Next.js 15, React 19, Tailwind, shadcn/ui
- **Backend:** tRPC, Prisma ORM, PostgreSQL (vector)
- **Auth:** Clerk (JWT, OAuth)
- **AI:** Google Gemini Pro, Assembly AI
- **Monitoring:** Sentry, Arcjet
- **Payments:** Stripe
- **Deployment:** Vercel
- **Key Folders:**
  - `src/app/` (pages, API)
  - `src/components/` (UI)
  - `src/lib/` (utils, integrations)
  - `src/server/` (tRPC, db)
  - `prisma/` (schema)
- **Style:** Modern, responsive, accessible, dark/light mode
- **CI/CD:** GitHub Actions, Husky, Conventional Commits
